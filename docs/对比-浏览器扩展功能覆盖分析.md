# AdGuard 浏览器扩展 vs 本模块功能对照分析

结论先行：**扩展的核心拦截能力本模块已覆盖且更强（系统级四层）；扩展独有的浏览器内特性分三类——已覆盖 / 内置未开 / 真缺口**。本文只分析，未改任何模块文件（用户要求先分析）。

## 一、扩展功能清单（源码核实，AdguardTeam/AdGuardBrowserExtension master）

设置枚举（Extension/src/background/schema/settings/enum.ts 全量 36 项）：
- 拦截类：FiltersState/GroupsState（过滤组开关）、CustomFilters（自定义过滤器 URL 导入）、UserFilterEnabled（用户规则）、AllowlistDomains/InvertedAllowlistDomains（白名单/反白名单）、AllowlistEnabled、DefaultAllowlistMode
- 隐身模式（Stealth）：DisableStealthMode、HideReferrer（隐藏 Referrer）、HideSearchQueries（隐藏搜索词）、SendDoNotTrack（DNT 头）、RemoveXClientData（删 X-Client-Data 头）、BlockFingerprinting（反指纹页面注入）、BlockWebRTC（WebRTC 泄露防护）、SelfDestructFirstParty/ThirdPartyCookies(+Time)（自动销毁 Cookie）
- 安全：DisableSafebrowsing（MV2 有，查 sb.adguard.com hash 前缀 + 警告页；MV3 注释明确 "we don't use safebrowsing service in MV3"）
- 体验类：页面统计、过滤日志（FilteringLog + PreserveLog）、右键菜单、外观主题、更新周期、命中统计（DisableCollectHits）、匿名使用数据、UseOptimizedFilters
- MV3 特有：user-scripts-api（scriptlet 注入）、rules-limits（3 万规则上限）、auto-disable-filters
- 元素级拦截：tswebextension 引擎做 cosmetic filtering（## 元素隐藏、#$# CSS 注入、HTML filtering、扩展 CSS）
- 本地 script rules 与 scriptlets（JS 注入页面）

## 二、逐项对照

| 扩展功能 | 本模块 | 状态 |
|---|---|---|
| 广告拦截（网络请求级） | AGH DNS 过滤 + SNI NFQUEUE（11 端口 RST）+ QUIC DROP + MITM URL 重写 | 超出：系统级全 App |
| 元素隐藏 ##（cosmetic CSS） | 无 CSS 引擎；MITM body-replace 可改 HTML 但无每页规则机制 | 真缺口（浏览器内 CSS 级） |
| 脚本注入/scriptlets | MITM goja JS 引擎（reject/302/header/body）+ 脚本页 2884 内置 | 覆盖（MITM 层，全局而非页面 DOM） |
| 自定义过滤器 URL 导入 | 「添加」list 页 2884 内置 + addurl 远程下载 + 文件上传 | 覆盖 |
| 用户规则编辑 | 拦截列表/白名单/自定义规则 + 脚本页编辑 | 覆盖 |
| 白名单/反白名单 | whitelist_filters（myallow）+ @@ 规则 | 覆盖 |
| 隐身-HideReferrer/HideSearchQueries/DNT/RemoveXClientData | MITM 已有 url-header-add/del 原语，缺规则入口与默认集 | 部分缺口（可做，中等工作量） |
| 隐身-SelfDestruct Cookies | 无（cookie 在浏览器进程内，网络层不可见） | 真缺口（原理性做不到） |
| BlockFingerprinting | 无页面 JS 注入层（body-replace 理论可注入，未做） | 缺口（可做但重） |
| BlockWebRTC | 隐私防护 AGH_PRIV 链挡 STUN/TURN 3478/3479/5349/5350 + mDNS | 覆盖（系统级） |
| Safebrowsing | fork 内置完整引擎，/control/safebrowsing/status 实测 {"enabled":false} | 内置未开（零工作量，打开即系统级 SB） |
| 过滤日志 | AGH 查询日志（内存）+ SNI 拦截计数 | 覆盖（形式不同） |
| 页面统计/右键菜单/主题 | 无对应 | 不适用（桌面浏览器 UX） |
| MV3 规则上限 30k | 无上限 | 超出 |
| DoH/DoT | dnsenc + SmartDNS | 超出 |

## 三、fork 独有能力（扩展完全没有）
- SNI 层：internal/snifilter NFQUEUE q7，11 TCP 端口 ClientHello 嗅探 + 明文 HTTP Host 嗅探，同规则库判定注入 RST；queuehealth 自监控
- QUIC 强制回落：DropQUIC UDP 443（v4+v6）
- MITM：动态签证书 TLS 解密 + goja JS 引擎（App 内 HTTPS 广告）
- /control/sni/status + /control/sni/set 面板开关
- 隐私防护页（DNS/VPN/IP 泄露防护，AGH_PRIV 链）
- SafeBrowsing/Parental 引擎内置（hashprefix.New home.go:494/523）

## 四、真缺口清单（若要「都支持」需补）
1. 浏览器内元素隐藏 CSS——网络层原理性做不到（每页面规则不同，MITM 注入不现实）
2. Cookie 自动销毁——浏览器进程内状态，原理性做不到
3. HTTP 头隐身（Referer/DNT/X-Client-Data）——MITM 原语已有，缺规则入口+默认集（中等工作量）
4. 反指纹 JS 注入——body-replace 可注入，需维护规则集（较大工作量）
5. Safebrowsing/Parental——代码全在，打开即得（零工作量）
